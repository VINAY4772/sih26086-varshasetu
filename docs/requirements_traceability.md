# Requirements Traceability Matrix (RTM): SIH26086
## Hyperlocal Monsoon Onset & Break Prediction System at Block/Village Scale
### Ministry of Earth Sciences (MoES) | Department: NCMRWF | Smart India Hackathon 2026

The following matrix traces every requirement specified in the SIH26086 Problem Statement to its implementation file, underlying data source, meteorological model or expert rule, UI/API touchpoint, verification method, and current verified status.

In accordance with strict verification integrity guidelines, only the five approved status values are used:
- **Implemented and tested**
- **Implemented but not fully validated**
- **Partially implemented**
- **Blocked by external dependency**
- **Not implemented**
